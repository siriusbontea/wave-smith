- 2026-11-10 **Grok hybrid is opt-in and lyrics-only.** Default connection is local. Key is `XAI_API_KEY` or `data/xai-api-key` (never SQLite, never returned by the API). Unrestricted lyrics skips Grok entirely because a hosted model may refuse; the local path still has no app-side content filter. Failures fall back to Ollama with a plain notice.
- 2026-11-10 **Section edit = turbo `repaint` (multipart `src_audio`, `chunk_mask_mode=explicit`).** New takes are child rows (`parent_song_id`, `edit_kind`); the original stays. Vocal-only swap is not implemented (repaint rewrites the whole range).
- 2026-11-10 **Extend = base `complete`, one DiT at a time.** Slot 1 is swapped to `acestep-v15-base` for the job and restored to turbo afterward (`ACESTEP_CONFIG_PATH2` is not set, so both DiTs are not resident). v0.1.8 does not pad `complete`, so the upload is the source plus a silent tail. The job still fails if the saved audio is not longer. Missing base weights are a setup error, not a silent turbo fallback (`model` would ignore an unloaded name).
- 2026-11-10 **Lyric timings are local stable-ts, not ACE-Step LRC.** REST and stored songs have no generation latents, so `get_lyric_timestamp` cannot run. Alignment prefers the vocals stem, stores JSON + LRC, and the editor falls back to tag estimates when timings are missing or stale. `MOCK_ENGINE` writes character-weighted demo times and labels them `mock`.
- 2026-11-10 **Demo mode does not invent a longer song.** Mock takes report the sample clip's length. Repaint and an extend that did not grow finish with `demoUnchanged` and no child row. Demo stems keep the source file extension. Base weights count only when a shard is at least 1 MiB, or an index points at shards that size. A repeated click key merges for 60 seconds. The same prompt without that key is a new job.
- 2026-11-10 **Language detection ignores bracketed structure tags.** `[verse]` and `[chorus]` are not Latin lyrics, so a Japanese or Arabic song is not marked mixed.
- 2026-11-11 **Phone access defaults to the Tailscale address, not 0.0.0.0.** The app stays on 127.0.0.1. A missing client header is not the Mac: the peer must be loopback and the gateway secret is separate. Home Wi-Fi is an explicit second toggle and does not survive a restart. Turn off revokes every phone. Codes expire in 10 minutes. Do not point Tailscale Serve or Funnel at port 3000.
- 2026-11-11 **A 100.64.0.0/10 address is not proof of Tailscale.** The door binds an address only when `tailscale ip` (or the Mac app CLI) reports it, or it is on `tailscale0`. Click keys use `getRandomValues` because `randomUUID` is missing on plain HTTP. Do not document `tailscale serve` against the phone door.
- 2026-11-11 **SQLite waits before WAL, and Tailscale lookup does not block the event loop.** `busy_timeout` is set before `journal_mode`. A busy switch is retried, and a file that is already WAL is left alone. `tailscale ip` is async, times out in 2 seconds, and is cached for 30 seconds. A timeout leaves the phone door closed. `X-Real-IP` that does not match the socket is a proxy, same as a forged `X-Forwarded-For`.
- 2026-11-11 **The Tailscale cache may delay opening the phone door, not closing it.** Every sync re-reads the interfaces. A missing address or a dropped `tailscale0` closes the listener before any CLI wait. Syncs run one at a time, and an older result is discarded. A CLI child that ignores SIGTERM is SIGKILLed, and the lookup fails closed at that deadline. The WebSocket proxy drops `X-Real-IP` the same way the HTTP proxy does.
- 2026-11-11 **Check again wins over a Settings poll, and an open door rechecks the CLI.** A cache-only poll does not bump the sync generation and does not apply while a refresh is pending; it waits for that refresh. While the door is open, a failed or timed-out CLI closes it even if the address is still on a local interface.
- 2026-11-11 **`wavesmith` is the install and the menu bar.** The Mac app only calls that command. `wavesmith start` binds the app and the engine to 127.0.0.1, keeps one pid file, and does not start a second copy. The LaunchAgent runs a local script and does not store `.env`. Setup writes `data/setup-progress.json` so the page can show download progress. A full desktop shell is still later.
- 2026-11-11 **A pid file is not a process.** stop, start, and the setup page trust a pid only when the command line and the recorded start time both match. A mismatch is stale and is not signalled. Concurrent starts share an atomic directory lock. A failed or stopped setup stays on screen with a next step, and the progress file survives the installer. The install one-liner is pinned to a commit. `update` stops a running app before git pull and starts it again afterwards. Launch at login starts the app now, and again at each login. Uninstall keeps the checkout so songs, `.env`, and models stay.
- 2026-11-11 **Uninstall never deletes a root.** A data, engine, or state path is removed only after realpath, and only when it sits inside the checkout, a known Wavesmith location, or a folder the installer marked. `/`, home, and their parents are refused. A pid matches an exact argv path, not a substring, and the executable has to be the real binary.
- 2026-11-11 **A system folder is not a Wavesmith folder.** Uninstall refuses every directory one level under `/`, plus `/private/tmp`, `/private/var`, and `/private/etc`, even when a marker is planted there. The marker is `setup-progress.json` with the fields the installer writes. A custom state directory can lose `wavesmith.pid` and `start.lock` without being deleted. An empty executable is not a match.
- 2026-11-11 **Uninstall deletes from an allowlist.** Recursive delete is `data/`, `engine/`, `node_modules`, and `.next` in the checkout, the known Wavesmith paths under home, or a custom data, engine, or state directory that is inside home and has the installer marker. `/usr/local`, `/opt/homebrew`, `/Library`, `/System`, and `/var/folders` are refused even with a forged marker.
- 2026-11-11 **A standard home folder is not a custom Wavesmith directory.** A custom data, engine, or state path is removed only when its real name contains "Wavesmith". Library, Documents, Desktop, Downloads, Music, Movies, Pictures, Public, Applications, .ssh, .gnupg, .config, .local, .cache, iCloud Drive, and Library/Application Support stay, even with a forged marker. Uninstall does not run when the checkout is the home folder or a parent of it. A known Wavesmith path that is a symlink is unlinked; the plan names the target and does not delete it.
